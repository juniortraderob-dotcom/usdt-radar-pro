# USDT Radar Pro — versão inicial\nInterface responsiva para computador e celular. Atualiza a consulta a cada 10 segundos; exibe spreads positivos em verde e negativos em vermelho caso venham a ser apresentados em detalhes. O quadro principal filtra oportunidades positivas.\n\nInclui as corretoras Binance, OKX, Kraken, Bybit, Ripio, BitcoinTrade, Bitget, Bitso, MEXC, KuCoin e Coinext; Mercado Bitcoin foi excluído. DEX inicial planejada: LlamaSwap na Polygon. Calculadora de custos opcional.\n\n**Atenção:** este pacote é a base visual e técnica. As integrações de APIs ainda não foram implementadas; por isso, não mostra cotações inventadas. Antes de usar para operar, será necessário integrar e validar individualmente cada API, par, livro de ofertas, taxas e liquidez.\n\nDeploy Netlify: publish directory `.`; functions directory `netlify/functions`; sem build command.\n
